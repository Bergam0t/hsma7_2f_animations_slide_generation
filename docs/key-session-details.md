This is a teaching session for the Health Service Modelling Associates Programme (HSMA).

Each session in HSMA is 6 hours in length.

## HSMA's approach to DES models

All models use a very similar structure throughout with a params, patient and model class.

More complex models will bring in a trial class for handling repeats of model runs.

## This Session

The aim of this session is to help them understand how to incorporate the package vidigi into their models to generate animations.

By the end of this session, students should be able to

- explain why animation can be a valuable part of simulation modelling
- add logging steps to an existing SimPy model
- set up a simple animation using vidigi's one-step animation function
- set up a more complex animation using vidigi's multi-step animation function
- effectively use key parameters in vidigi's animation functions
- override icons in an animation to identify patients with different attributes
- create process maps
- set up an instance of vidigi's TrialLogger class
- use the plotting helpers from EventLogger and TrialLogger to evaluate model runs

## The students

The students are analysts, clinicians and managers in the UK National Health Service. Their prior experience with programming before joining the course will vary from none to extensive.

Students on the course have received training in Python and discrete event simulation principles and coding with SimPy and Tom Monk's package sim-tools prior to this point.

## Position in flow of module

This session is in module 2.

Module 0 introduces operational research and data science.

Module 1 introduces Python across 30 hours of training.

This session is 2F.

2A: Introduction to Discrete Event Simulation (concepts, no programming)
2B: Introduction to SimPy (Generator Functions, Object Oriented Programming and SimPy Basics)
2C: SimPy Part 2 (Replications, Reproducibility and Multiple Activities)
2D: SimPy Part 3 (Warm Up, Time Dependent Distributions and Resource Unavailability)
2E: SimPy Part 4 (Priority Queuing, Resource Utilisation, Reneging and Governor Models)
